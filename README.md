# 🔐 Personal Data Vault API - apiromwiner

> Bóveda segura para datos personales con cifrado AES-256-GCM, consentimiento granular y auditoría completa.

## ✨ Características

- 🔒 Cifrado de extremo a extremo (AES-256-GCM)
- 🤝 Consentimiento con expiración y revocación
- 📋 Auditoría inmutable de todos los accesos
- 🚦 Rate limiting y protección contra ataques
- ✅ Validación estricta de esquemas con Joi
- 🌐 CORS configurado de forma segura
- 🧹 Limpieza automática de consentimientos expirados

## 🚀 Instalación Rápida

```bash
# 1. Clonar el repositorio
git clone https://github.com/tu-usuario/personal-data-vault.git
cd personal-data-vault

# 2. Instalar dependencias
npm install

# 3. Configurar variables de entorno
cp .env.example .env
# ← Edita .env con tus valores reales (¡nunca lo subas a GitHub!)

# 4. Iniciar el servidor
npm start
```
