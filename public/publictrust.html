🔧 1. Arquitectura Técnica: 100% Local, Cero Dependencias Externas

✅ Sin CDNs ✅ Sin APIs de terceros ✅ Funciona offline ✅ Zero-Dependency

Principio fundamental: Todo el procesamiento crítico ocurre en tu dispositivo. ApiRomwiner Vault no depende de servidores externos para funcionar.

✅ Componentes 100% locales implementados:

  • Generación de QRs: Canvas nativo + algoritmo determinista. Sin api.qrserver.com.
  • Hash de firma: Web Crypto API (crypto.subtle.digest('SHA-256')). Sin CryptoJS.
  • Avatar por defecto: SVG embebido en data URL. Sin dicebear.com.
  • Analytics y gráficos: CSS Flexbox + Canvas nativo. Sin Chart.js.
  • Almacenamiento local: localStorage y sessionStorage para preferencias y tokens de sesión.
  • PWA: Service Worker registrado localmente para caché y funcionamiento offline.
🔍 Verificación independiente: Puedes auditar nuestro código fuente en GitHub. Para verificar que no hay llamadas externas: abre las DevTools de tu navegador (F12 → pestaña Network), recarga la página y filtra por qrserver, crypto-js, dicebear, chart. Resultado esperado: "No results".

🔐 2. Cifrado y Protección de Datos

✅ AES-GCM-256 ✅ Envelope Encryption ✅ Claves únicas por usuario ⚠️ Zero-Knowledge opcional

Cómo protegemos tus archivos:

  • Envelope Encryption: Cada usuario tiene una clave de cifrado única (DEK), que a su vez se cifra con una clave maestra (KEK) almacenada de forma segura en el backend.
  • Algoritmo: AES-GCM-256 (estándar NIST, compatible con FIPS 140-2).
  • Modo Zero-Knowledge (opcional): Si activas esta opción en tu panel, el cifrado ocurre en tu navegador antes de enviar los datos. En este modo, ni siquiera nosotros podemos acceder a tu contenido.

Protección de credenciales:

  • Contraseñas: Hash con bcrypt + salt único por usuario. Nunca almacenamos texto plano.
  • Tokens de sesión: JWT firmados con HS256, expiración configurable, revocación inmediata al cerrar sesión.
  • Autenticación de dos factores (2FA): Disponible para planes Business/Enterprise.
⚠️ Limitación importante: El modo Zero-Knowledge es opcional. Si no lo activas, tus archivos se cifran en tránsito y en reposo, pero ApiRomwiner Vault posee las claves técnicas para acceder a ellos (por ejemplo, para recuperación de cuenta o cumplimiento legal). Recomendación: Activa Zero-Knowledge para máxima privacidad.

🔒 3. Privacidad y Cumplimiento GDPR

✅ Minimización de datos ✅ Derecho al olvido ✅ Portabilidad de datos ✅ GDPR-ready

Datos que recopilamos:

  • Para crear tu cuenta: Email (verificado), contraseña (hash), nombre de usuario opcional.
  • Para funcionar: Token de sesión (almacenado en localStorage), preferencias de UI (tema, idioma), código de referido (si aplica).
  • Para analytics internos: Logs de errores anónimos (sin PII), métricas de uso agregadas (ej: "100 usuarios activaron Zero-Knowledge esta semana").

Datos que NO recopilamos:

  • 🚫 Dirección IP (no la almacenamos en logs persistentes)
  • 🚫 Ubicación geográfica
  • 🚫 Dispositivo o navegador específico (más allá del user-agent para debugging)
  • 🚫 Contenido de tus archivos (a menos que no uses Zero-Knowledge y sea necesario para soporte técnico)
  • 🚫 Cookies de terceros ni trackers de analytics externos

Tus derechos (GDPR/LOPDGDD):

  • Acceso: Solicita una copia de tus datos personales.
  • Rectificación: Corrige información inexacta.
  • Eliminación ("Derecho al olvido"): Solicita la eliminación permanente de tu cuenta y datos asociados.
  • Portabilidad: Exporta tus datos en formato JSON/CSV legible.
  • Oposición: Opt-out de comunicaciones promocionales.

Ejercicio de derechos: Envía tu solicitud a privacy@apiromwinervault.com con asunto "Ejercicio de derechos GDPR". Respondemos en ≤ 30 días.

🔍 4. Auditoría y Transparencia

✅ Logs inmutables ✅ Hashing encadenado SHA-256 ✅ Firmas HMAC

Integridad de logs:

  • Cada acción crítica (login, subida de archivo, cambio de configuración) genera un registro con: timestamp, ID de usuario (hash), acción, y hash del registro anterior.
  • Los logs forman una cadena: modificar un registro rompe el hash del siguiente → detectable inmediatamente.
  • Firmas HMAC-SHA256 garantizan que los logs no fueron alterados en tránsito.

Transparencia para usuarios:

  • Panel de actividad: En tu dashboard, revisa tu historial de acciones con timestamp y dispositivo.
  • Exportación: Descarga tus logs personales en formato JSON (planes Business/Enterprise).
  • API de estado: Consulta el estado técnico de seguridad de tu cuenta: 
    GET https://api.romwinervault.com/api/security/status
Headers: Authorization: Bearer <tu_token>

Certificaciones en progreso:

  • 🔄 SOC 2 Type I (en proceso de auditoría)
  • 🔄 ISO 27001 (planificado para Q4 2026)
  • ✅ Cumplimiento GDPR/LOPDGDD (implementado)

⚖️ 5. Responsabilidades del Usuario

Tú eres responsable de:

  • Guardar tu contraseña: ApiRomwiner Vault no puede recuperarla si la olvidas (especialmente en modo Zero-Knowledge). Usa un gestor de contraseñas.
  • Proteger tu dispositivo: Si alguien accede a tu dispositivo desbloqueado, podrá acceder a tu cuenta. Usa bloqueo de pantalla y actualizaciones de seguridad.
  • Verificar la URL: Asegúrate de estar en https://api.romwinervault.com (o tu dominio personalizado) para evitar phishing.
  • Reportar accesos no autorizados: Si sospechas compromiso, cambia tu contraseña inmediatamente y contacta a seguridad.

ApiRomwiner Vault se compromete a:

  • Notificarte en ≤ 72 horas si detectamos un acceso no autorizado a tu cuenta.
  • Proporcionar herramientas para revocar sesiones activas remotamente.
  • Mantener esta página de seguridad actualizada con cambios relevantes.

Tu diligencia es la primera línea de defensa.
